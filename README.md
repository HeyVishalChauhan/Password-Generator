# 🔐 Password Generator

A secure and user-friendly password generator built with Python and Tkinter.

## ✨ Features

- Generate secure random passwords
- Generate multiple passwords at once
- Custom password length
- Include numbers
- Include symbols
- Password strength indicator
- Show / Hide passwords
- Copy individual passwords
- Clear generated passwords
- Input validation
- Uses Python's `secrets` module

## 🛠️ Technologies Used

- Python
- Tkinter
- Secrets
- String

## 🚀 How to Run

1. Install Python 3.x
2. Clone this repository
3. Open the project folder
4. Run:

```bash
python password_generator.py
